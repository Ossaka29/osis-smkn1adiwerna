CARA PASANG (XAMPP)
1. Salin folder "msc" ke C:\xampp\htdocs\
2. Jalankan Apache + MySQL, buka http://localhost/phpmyadmin -> tab Import -> pilih db.sql
3. Website : http://localhost/msc/public/index.php
4. Admin   : http://localhost/msc/admin/login.php  
Jika MySQL Anda memakai password, ubah di inc.php.
